# Password Generator

A Python program that generates a random password based on the length specified by the user.
The user can choose whether to include numbers and symbols.

## Features
- User chooses password length
- Optional numbers and symbols
- Randomly shuffles the password
- Guarantees at least one number and/or symbol if selected
- Validates that password length is at least 4 characters

## Technologies Used
- Python 3
- random
- string

## How to Run
```bash
python password_generator.py
```
## Example Output
```text
Enter password length: 6

Do you want numbers in your password (Y/N)? y
Do you want symbols in your password (Y/N)? y

Generated Password: 7vd@;3
```
